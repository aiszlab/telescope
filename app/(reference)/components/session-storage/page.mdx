# SessionStorage 会话存储

SessionStorage 组件，用于在浏览器 sessionStorage 中存储键值对数据。

## 何时使用

当需要在浏览器会话期间临时存储数据时使用，页面关闭后数据自动清除。

### SessionStorage Props

| 参数  | 说明     | 类型     | 默认值 |

| value | 存储值   | `string` | —      |

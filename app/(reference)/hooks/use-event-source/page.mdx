# useEventSource

管理 `EventSource`（SSE）连接的钩子。组件挂载时建立连接，卸载时自动关闭。

## API

### Parameters

| 参数 | 说明         | 类型     | 默认值 |
| ---- | ------------ | -------- | ------ |
| url  | SSE 服务地址 | `string` | -      |

### Return

无。连接在组件挂载时建立，卸载时自动关闭。

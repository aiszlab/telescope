图片加载状态钩子，返回图片的加载状态。

## API

### Parameters

| 参数           | 说明          | 类型                          | 默认值       |
| -------------- | ------------- | ----------------------------- | ------------ |
| src            | 图片地址      | `string`                      | -            |
| crossOrigin    | 跨域设置      | `string`                      | -            |
| referrerPolicy | referrer 策略 | `HTMLAttributeReferrerPolicy` | `no-referrer` |

### Return

| 参数   | 说明     | 类型                                          |
| ------ | -------- | --------------------------------------------- |
| status | 加载状态 | `'none' \| 'loading' \| 'error' \| 'loaded'` |

# useInfiniteScroll

无限滚动钩子，基于 `IntersectionObserver` 检测哨兵元素是否进入视口，触发加载更多。

## API

### Parameters

| 参数       | 说明             | 类型         | 默认值 |
| ---------- | ---------------- | ------------ | ------ |
| hasMore    | 是否还有更多数据 | `boolean`    | `true` |
| distance   | 触发距离（px）   | `number`     | `0`    |
| onLoadMore | 加载更多回调     | `() => void` | -      |

### Return

| 参数        | 说明         | 类型                   |
| ----------- | ------------ | ---------------------- |
| sentinelRef | 哨兵元素 ref | `RefObject<T \| null>` |
| viewportRef | 滚动视口 ref | `RefObject<T \| null>` |

# useLazyMemo

惰性 `useMemo`，仅当读取 `value` 时才执行计算，避免在 render 阶段同步阻塞。

## API

### Parameters

| 参数 | 说明     | 类型         | 默认值 |
| ---- | -------- | ------------ | ------ |
| fn   | 计算函数 | `() => T`    | -      |
| deps | 依赖项   | `unknown[]`  | -      |

### Return

| 参数 | 说明             | 类型           |
| ---- | ---------------- | -------------- |
| memo | 惰性计算代理对象 | `{ value: T }` |

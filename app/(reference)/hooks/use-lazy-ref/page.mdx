# useLazyRef

惰性 ref 钩子，返回一个取值函数，仅在首次调用时执行 getter 并缓存结果。

## API

### Parameters

| 参数   | 说明         | 类型      | 默认值 |
| ------ | ------------ | --------- | ------ |
| getter | 取值工厂函数 | `() => T` | -      |

### Return

| 参数   | 说明             | 类型      |
| ------ | ---------------- | --------- |
| getter | 取值函数（惰性） | `() => T` |

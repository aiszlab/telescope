# useLocalStorageState

将状态持久化到 `localStorage` 的钩子，支持监听跨标签页的同步变化。

## API

### Parameters

| 参数   | 说明                     | 类型      | 默认值  |
| ------ | ------------------------ | --------- | ------- |
| key    | 存储键名                 | `string`  | -       |
| listen | 是否监听跨标签页变化     | `boolean` | `true`  |

### Return

| 参数     | 说明     | 类型                              |
| -------- | -------- | --------------------------------- |
| value    | 当前值   | `string \| null`                  |
| setValue | 设置函数 | `(value: string \| null) => void` |

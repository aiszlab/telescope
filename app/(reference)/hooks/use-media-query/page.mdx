## API

### Parameters

| 参数  | 说明           | 类型                 | 默认值 |
| ----- | -------------- | -------------------- | ------ |
| query | 媒体查询字符串 | `string \| string[]` | -      |

### Return

| 参数   | 说明                 | 类型        |
| ------ | -------------------- | ----------- |
| result | 各查询是否匹配的数组 | `boolean[]` |

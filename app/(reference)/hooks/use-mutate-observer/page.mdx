## API

### Parameters

| 参数     | 说明               | 类型                                        | 默认值 |
| -------- | ------------------ | ------------------------------------------- | ------ |
| elements | 观察的目标元素     | `HTMLElement \| HTMLElement[] \| null`      | -      |
| callback | 变化回调           | `MutationCallback`                          | -      |

### Return

无。

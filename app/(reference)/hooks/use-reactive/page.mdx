## API

### Parameters

| 参数         | 说明     | 类型       | 默认值 |
| ------------ | -------- | ---------- | ------ |
| initialState | 初始状态 | `State<T>` | -      |

### Return

| 参数     | 说明           | 类型           |
| -------- | -------------- | -------------- |
| reactive | 响应式代理对象 | `{ value: T }` |

# useScreenSize

获取当前视口（窗口）尺寸的钩子，窗口变化时自动更新。

## API

### Return

| 参数   | 说明   | 类型     |
| ------ | ------ | -------- |
| width  | 视口宽 | `number` |
| height | 视口高 | `number` |

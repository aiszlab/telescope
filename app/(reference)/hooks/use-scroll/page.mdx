## API

### Parameters

| 参数     | 说明         | 类型                     | 默认值 |
| -------- | ------------ | ------------------------ | ------ |
| callback | 滚动回调函数 | `(event: Event) => void` | -      |

### Return

| 参数  | 说明           | 类型         |
| ----- | -------------- | ------------ |
| clean | 取消监听的函数 | `() => void` |

# useSessionStorageState

将状态持久化到 `sessionStorage` 的钩子，数据仅在当前标签页会话内有效。

## API

### Parameters

| 参数   | 说明                     | 类型      | 默认值  |
| ------ | ------------------------ | --------- | ------- |
| key    | 存储键名                 | `string`  | -       |
| listen | 是否监听存储变化         | `boolean` | `true`  |

### Return

| 参数     | 说明     | 类型                              |
| -------- | -------- | --------------------------------- |
| value    | 当前值   | `string \| null`                  |
| setValue | 设置函数 | `(value: string \| null) => void` |

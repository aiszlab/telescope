# useTimeout

定时器钩子，在 `wait` 毫秒后执行回调，支持立即触发（`flush`）与取消（`cancel`）。

## API

### Parameters

| 参数     | 说明           | 类型          | 默认值 |
| -------- | -------------- | ------------- | ------ |
| callback | 回调函数       | `AnyFunction` | -      |
| wait     | 等待时间（毫秒） | `number`     | -      |

### Return

| 参数   | 说明         | 类型         |
| ------ | ------------ | ------------ |
| flush  | 立即触发回调 | `() => void` |
| cancel | 取消定时器   | `() => void` |

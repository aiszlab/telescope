# useTimer

定时器管理钩子，提供设置与清除定时器的能力，组件卸载时自动清理。

## API

### Return

| 参数    | 说明                       | 类型                                              |
| ------- | -------------------------- | ------------------------------------------------- |
| timeout | 设置定时器（会清除上一个） | `(handler: VoidFunction, duration?: number) => void` |
| clear   | 清除当前定时器             | `() => void`                                      |

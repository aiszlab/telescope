## throttle 节流

## 使用场景

限制函数调用频率，在指定时间间隔内只执行一次，常用于滚动事件、按钮点击等场景

## 代码演示

```ts
import { throttle } from '@aiszlab/relax'

const throttled = throttle((event: MouseEvent) => {
  console.log('click:', event.clientX, event.clientY)
}, 1000)

window.addEventListener('click', (event) => {
  throttled.next(event) // 每秒最多执行一次
})

// 立即执行
throttled.flush()

// 取消等待中的调用
throttled.abort()
```

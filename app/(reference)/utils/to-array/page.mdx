## toArray 转换为数组

## 使用场景

将任意类型数据转换为数组，是处理不确定类型输入的通用工具

## 代码演示

```ts
import { toArray } from '@aiszlab/relax'

toArray(null) // => []
toArray(undefined) // => []
toArray([1, 2, 3]) // => [1, 2, 3]
toArray('hello') // => ['hello']
toArray(new Set([1, 2, 3])) // => [1, 2, 3]
toArray(42) // => [42]
```
